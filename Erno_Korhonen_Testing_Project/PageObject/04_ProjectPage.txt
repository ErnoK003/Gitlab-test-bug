# Positive Test examples are below write test process steps for each below test case

	Create-1: Create blank project
		Navigate to Projects Page  NewProjectUrl
		Select Create blank project
		Input Project name  ProjectName
		Select group for Project URL  GroupName
		Select Create Project
		Verify That Info Message should show Project  'ProjectName'  was successfully created.

	Create-2: Create template project 
		Navigate to Projects Page  NewProjectUrl
		Select Create from template
		Select Template  TemplateName
		Input Project name  ProjectName
		Select group for Project URL  GroupName
		Select Create Project
		Wait for importing
		Verify That Info Message should show The project was successfully imported.

	Update-1: Update name of template project
		Navigate to EditProjectUrl, where  ProjectName  is name of existing template project.
		Input Project name  EditedName
		Select Save changes
		Verify That Info Message should show Project ' EditedName ' was successfully updated.

	Delete-1: Delete template project
		Navigate to EditProjectUrl, where  ProjectName  is name of existing template project.
		Expand Advanced
		Find Delete project
		Select Delete
		Input  GroupName/ProjectName
		Select Yes, delete project
		Verify that the deleted project shows up in Inactive -tab under Projects.
